# Medical Insurance Cost Analysis Using Statistical Modeling

## 1. Project Overview

This project analyses medical insurance charges using exploratory data analysis, statistical hypothesis testing, and Ordinary Least Squares regression.

The project uses the Medical Insurance Costs dataset, which contains information about individuals such as:

- Age
- Sex
- Body Mass Index
- Number of children
- Smoking status
- Residential region
- Medical insurance charges

The main objective is to understand which factors are associated with medical insurance charges and to build an interactive dashboard for data exploration, statistical testing, regression analysis, and prediction.

## 3. Problem Statement

Medical insurance charges may vary depending on demographic, lifestyle, and health-related factors.

This project investigates the relationship between insurance charges and the following explanatory variables:

- Age
- BMI
- Number of children
- Sex
- Smoking status
- Region

The project also evaluates whether insurance charges differ significantly between selected groups and whether an OLS regression model can explain and predict insurance charges.
